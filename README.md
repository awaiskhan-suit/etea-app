# 🎓 ETEA-Style Test Management App

A mobile **Test Management Application** designed to provide students with a convenient platform to apply for tests, access their roll numbers, download roll number slips, and view their test results.

The application also provides administrative functionality for managing student applications and assigning roll numbers.

> **Note:** This is an educational/demo application inspired by the workflow of test management platforms. It is not an official ETEA application.

## 🚀 Key Features

### 🌟 Splash Screen

The application starts with a professional **Splash Screen** before navigating users to the main landing page.

### 🏠 Landing Page

The landing page provides students with access to the major test-related features, including test application, roll number information, roll number slip, and result checking.

### 📝 Student Test Application

Students can apply for a test through the application by providing the required information.

The application manages the student's test application and allows the student to access their test-related information.

### 👨‍💼 Admin Roll Number Management

The admin can manage student applications and **assign roll numbers to students**.

Once a roll number has been assigned, the student can retrieve their roll number using their **CNIC**.

### 🔢 Roll Number Checking

Students can enter their CNIC to check their assigned roll number.

The application displays the student's relevant roll number information after successful verification.

### 📄 Roll Number Slip

Students can view their **Roll Number Slip** and download it in **PDF format**.

The PDF provides students with a digital copy of their examination information for future use.

### 📊 Result Management

Students can also check their test results through the application.

After entering the required identification information, students can view their result details.

### 📥 Result PDF

The application also allows students to **download their result in PDF format**, making it easy to save and share their result information.

## 🎯 Project Objective

The main objective of this project is to develop a **digital test management system** that simplifies the process of student test applications, roll number assignment, roll number slip generation, and result management.

The project demonstrates practical implementation of **student management, admin functionality, identification-based searching, PDF generation, document downloading, and a structured examination workflow**.
